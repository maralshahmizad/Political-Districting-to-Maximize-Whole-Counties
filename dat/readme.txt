This 'dat' folder should contain all the input data for the experiments.

This includes JSON files (.json) for the input graphs (at county, tract, and block levels). This is available from the authors upon request (after agreeing to the terms set by the Redistricting Data Hub--which essentially say not to gerrymander).

It should also include shapefiles (.shp) for each state at the county level. This is used to draw the initial inequalities.

Also, the number of whole counties is calculated from BAFs stored in the following subfolders:  
1. cd118 (congressional districts for 118th congress)
2. sldl2022 (state house districts in 2022)
3. sldu2022 (state senate districts in 2022)
The former is available from the US Census Bureau at:
  https://www.census.gov/programs-surveys/decennial-census/about/rdo/congressional-districts.html
And the latter two are available from:
  https://www.census.gov/programs-surveys/decennial-census/about/rdo/state-legislative-district.html
